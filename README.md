# آشا شاپ - بازار دیجیتال و فیزیکی

یک فروشگاه آنلاین مدرن برای فروش محصولات دیجیتال و فیزیکی.

## ویژگی‌ها

- 🏠 صفحه خانگی جذاب
- 📱 کاتالوگ محصولات ریسپانسیو
- 🛒 سبد خرید کامل
- 💳 تسویه‌حساب ۳ مرحله‌ای
- 🎨 طراحی مدرن

## نحوه استفاده

فایل HTML را با مرورگر باز کنید.

## تکنولوژی

- HTML5, Tailwind CSS, JavaScript
